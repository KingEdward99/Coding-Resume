## Project Summary: “ADC Gatekeeper” – An Automated DevSecOps Verification Pipeline

## Description 

An automated, full-stack application designed to simulate the security and compliance verification pipeline for software slated for deployment into a high-security cloud environment like AWS GovCloud (an “Amazon Dedicated Cloud”)

The tool provides a user-friendly front-end for submissions, a back-end engine that performs automated security scans, and a database to track the status of all submissions

 

## Technology Stacks

- Front-End: React.JS
- Back-End: Python (with Flask or FastAPI)
- Database: MySQL
- Security Tooling: Integrated open-source SAST (Static Application Security Testing) and DAST (Dynamic Application Security Testing) Tools
