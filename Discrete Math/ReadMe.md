
# Discrete Math — Program Collection

This repository contains a set of foundational programs written in **C++**, **Python**, and **Java** as part of my **Discrete Mathematics** coursework. Each assignment demonstrates applies core mathematical concepts through practical implementations in code

---

## Overview of Programs

### **1. Encryption (Python) **
This program implements a basic **Caesar Cipher** system that allows users to encrypt or decrypt a message using a fixed shift of 5. The user selects an option form a simple menu, enters a message, and the program applies character-by-character transformation using ASCII values.
- encrypts a message that a user enters

**Concepts demonstrated:** 
- string manipulation
- ASCII character encoding
- Caesar Cipher logic
- control flow
- user input handling

---

### **2. Graph (Python)**
This program models a neighborhood as an undirected graph, where each house is represented as a node and each path between houses is represented as an edge. After constructing and visualizing the graph, the program determines whether it contains an Eulerian path, an Eulerian cycle, or is not Eulerian.

The program uses **NetworkX** to build and draw the graph, and implements its own logic, using **Breadth-First Search** and degree analysis, to classify the graph's Eulerian status.


**Concepts demonstrated:** 
- graph theory
- Breadth-First Search
- Eulerian paths and cycles
- degree of vertices
- graph visualization

---

### **3. Laker Sets (Python)**
This program uses the 2025-2026 Los Angeles Lakers roster to simulate and explore fundametial set-theory operations. Players are grouped into three sets: guards, forwardsa and centers

The user can interactively perform operations such as unions, cardinality checks, and Cartesian-product-style duo generation.

**Concepts demonstrated:** 
- set theory
- union of sets
- cardinality
- Cartesian products
- basic combinatronics
- control flow
- list operations
---

### **4. Neighborhood (Python)**
This program models a neighborhood as an undirected graph, where each house is represented as a node and each path between houses is represented as an edge. After constructiong and visualizing the graph, the program uses a **recursive backtracking algorithm** to determine a **Hamiltonian Path** exists.

**Concepts demonstrated:** 
- Hamiltonian paths
- Graph traversal
- Recursive backtracking
- Search algorithms
- Graph representation

---

### **5. Permutation / Combination Calculator (Python)**
This program provides an interactive calculator for two foundational combinatronics operations: **permuations** and **combinatronics**. After the user inputs values for n (total items) and r(items selected), the program computers the result using factorial-based formulas implemented manually through iterative loops. 

**Concepts demonstrated:** 
- Permutations
- Combinations
- Factorials
- Iterative algorithms
- Combinatorics
- Control Flow
- User Input Handling

---

### **6. Sequence (Java)**
This program computers the first 20 terms of a sequence defined by a **second-order linear recurrence relations**. The user provides four constants:
- c1 and c2: coefficients for the recurrence
- c3 and c4: initial terms a1 and a2
The program then iteratively generates the remaining terms.

**Concepts demonstrated:** 
- recurrence relations
- sequence generation
- iterative computation
- array manipulation
- mathematical modeling
---

### **7. Union & Intersection (C++)**
This program implements two fundamental set-theory operations, **union** and **intersection**, using arrays and manual comparison logic. After the user inputs the size and elements of two sets, the program constructs each set, displays the values, and computers the union and intersection.  

**Concepts demonstrated:** 
- Set operations
- Union of sets
- Intersection of sets
- Array manipulation
- Nested Iteration
- Procedural Programming
